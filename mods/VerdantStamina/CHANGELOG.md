# Changelog

## 0.1.0-alpha.3 — 2026-11-15

Initial version tracked in the Windrose monorepo, renamed from WindroseStamina to Verdant Stamina.

- Smooth concentric stamina rings with worn-paint, hatch and flat surfaces.
- Separate permanent capacity and temporary food/buff reserve using native effect data.
- Low-stamina color transition, HUD reconstruction recovery and diagnostics.
- F8 toggle, F9 diagnostics and F10 source reload.

Earlier alpha development predates Git history. This entry records the imported baseline; it does not claim a new public release or completed live validation of the rename.
